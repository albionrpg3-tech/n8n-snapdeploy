# n8n-snapdeploy

Deploy de n8n en SnapDeploy con base de datos Supabase.

## Configuración
Requiere variables de entorno para Supabase:
- DB_POSTGRESDB_HOST
- DB_POSTGRESDB_PORT
- DB_POSTGRESDB_USER
- DB_POSTGRESDB_PASSWORD
- DB_POSTGRESDB_DATABASE
- N8N_ENCRYPTION_KEY

## Acceso
Después del deploy, accede a tu URL de SnapDeploy para crear tu cuenta de administrador.
